# Module 00: Environment Setup & ChipWhisperer Introduction

## Learning Objectives

By the end of this module, you will be able to:

1. Install and configure the ChipWhisperer software environment
2. Set up Python virtual environments and required dependencies
3. Connect to ChipWhisperer hardware (CW-Lite, CW-Nano, etc.)
4. Run basic capture scripts and verify system functionality
5. Understand the ChipWhisperer architecture and component relationships

## Time Estimate

**2 hours**

## Prerequisites

- Basic Python programming knowledge
- Command-line interface familiarity
- Git version control basics

## Module Content

This introductory module provides the foundation for all subsequent modules. You will:

- Install ChipWhisperer software stack
- Configure Python environments with required packages
- Set up hardware connections and verify communication
- Run your first side-channel capture
- Understand the ChipWhisperer ecosystem
