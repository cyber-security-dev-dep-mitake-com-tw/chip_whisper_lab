# Module 33: FIPS 140-3 Modern Framework

## Learning Objectives
- Explain why NIST introduced FIPS 140-3 and how it differs from FIPS 140-2
- Understand the alignment with ISO/IEC 19790 and ISO/IEC 24759
- Identify the new mandatory non-invasive (side-channel) attack mitigation requirement (SP 800-140F)
- Understand the FIPS 140-2 → FIPS 140-3 transition/sunset timeline

## Estimated Time
1 hour

## Prerequisites
- Module 32 (FIPS 140-2 Overview)

## Key Topics
1. ISO/IEC 19790 and ISO/IEC 24759 alignment
2. Mandatory non-invasive attack (SCA) mitigation evidence (NIST SP 800-140F)
3. Life-cycle assurance requirements
4. Zeroization strengthening
5. CMVP transition timeline and Historical List
