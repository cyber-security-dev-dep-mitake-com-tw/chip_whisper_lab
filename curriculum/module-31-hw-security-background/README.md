# Module 31: Background of Hardware Security (硬體安全的背景與演進)

## Learning Objectives
- Explain the paradigm shift from software-only protection to hardware-rooted trust
- Describe how the globalized, fabless IC supply chain creates the need for a hardware security ecosystem
- Classify the four core hardware threat categories: Trojans, side-channel, reverse engineering, counterfeiting
- Understand Security-by-Design, PPAS, and the Secure Hardware Development Lifecycle
- Identify key regulations/standards driving hardware security adoption (ISO/SAE 21434, NIST IR 8259, DARPA SSITH)

## Estimated Time
1–1.5 hours

## Prerequisites
- Module 01 (Chip Security Landscape)

## Key Topics
1. Software-trust assumption vs. Layer-0 hardware trust
2. Fabless/global supply chain risk (3rd-party IP, foundry, OSAT)
3. Hardware Trojans, side-channel attacks, reverse engineering, counterfeiting
4. Security-by-Design, PPAS, Secure HDLC
5. ISO/SAE 21434, NIST IR 8259, ETSI EN 303 645, DARPA SSITH
